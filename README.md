# EcoLife 绿色生活助手 🌱

**EcoLife** 是一款基于数据驱动和人工智能（AI）赋能的可持续生活伴侣 Web 应用。它旨在通过数字化工具、游戏化体验和社区互动，帮助用户轻松践行低碳生活，记录环保足迹，并发现身边的绿色伙伴。

本项目完全采用前端技术栈构建，利用 **Google Gemini API** 提供强大的 AI 智能分析、图像识别和内容生成能力。

---

## 核心功能 ✨

### 1. 📊 碳足迹追踪 (Carbon Tracker)
量化您的日常环境影响，让减排看得见。
*   **多维记录**：支持记录私家车出行（公里）、家庭用电（度）和肉食餐数。
*   **可视化图表**：实时生成饼图，直观展示各项碳排放占比。
*   **AI 智能点评**：Gemini 会化身幽默的“环保老友”，根据您的数据生成个性化的减排建议和趣味挑战，告别枯燥的数据罗列。

### 2. ♻️ 智能垃圾分类 (AI Recycle Assistant)
拍照即懂，垃圾分类不再是难题。
*   **视觉识别**：上传或拍摄物品照片，AI 自动识别物品名称。
*   **分类指导**：精准判断属于“可回收物”、“有害垃圾”、“厨余垃圾”还是“其他垃圾”，并提供具体的投放建议。
*   **极速体验**：内置图片压缩算法，确保在移动端也能快速响应。

### 3. 🏘️ 绿色真实社区 (Eco Community)
连接同城的环保邻居，打造有温度的本地社区。
*   **闲置市集**：发布“赠送”或“求购”信息，促进物品循环利用。
*   **社区活动**：发起或参与夜跑、净塑、旧物改造等线下活动。
*   **智能内容风控**：**新增功能！** 在发布信息时，AI 会实时核验文本内容，自动过滤暴力、色情或违规交易信息，维护社区健康。
*   **混合数据生态**：结合用户本地发布的真实数据与 AI 模拟的“虚拟邻居”数据，营造活跃的社区氛围。
*   **安全校验**：内置手机号格式校验，确保联系方式真实有效。

### 4. 🌱 习惯养成与成长体系 (Habit Growth)
游戏化机制，让坚持环保变得有趣。
*   **每日打卡**：预设“自带水杯”、“光盘行动”等环保任务，完成即可获得积分。
*   **等级系统**：积累 XP 升级，从“环保新手”成长为“环保卫士”。
*   **积分商城**：使用环保积分兑换虚拟权益（如优惠券、公益证书），模拟真实的奖励反馈闭环。

### 5. 🧠 环保百科挑战 (Eco Quiz)
寓教于乐，随时随地涨知识。
*   **AI 出题**：利用 AI 实时生成关于垃圾分类、气候变化、可持续生活的单选题。
*   **即时反馈**：答题后立即显示解析，帮助用户巩固环保知识。

### 6. 💬 绿色顾问 (Green Advisor)
您的专属 24 小时环保百科全书。
*   **智能问答**：基于 Gemini 大模型，回答关于零浪费生活、节能技巧等任何问题。
*   **上下文理解**：支持多轮对话，提供像聊天一样的自然交互体验。

## 技术栈 🛠️

*   **前端框架**: React 19
*   **构建工具**: Vite (通过 esm.sh 引入)
*   **样式库**: Tailwind CSS (响应式设计，不仅美观且适配移动端)
*   **人工智能**: Google Gemini API (`gemini-2.5-flash` 模型)
    *   文本生成与推理
    *   视觉识别 (Multimodal)
    *   内容安全审核
    *   结构化数据生成 (JSON Mode)
*   **图表库**: Recharts
*   **数据存储**: LocalStorage (纯前端持久化，无需后端数据库)

## 快速开始 🚀

1.  **获取 API Key**:
    本项目依赖 Google Gemini API。请前往 [Google AI Studio](https://aistudio.google.com/) 获取您的 API Key。

2.  **配置环境**:
    在项目根目录设置环境变量 `API_KEY`（在当前演示环境中，API Key 通过 `process.env.API_KEY` 自动注入）。

3.  **安装依赖**:
    ```bash
    npm install
    ```

4.  **启动项目**:
    ```bash
    npm start
    ```

## 隐私说明 🔒

本项目主要是一个前端演示应用。
*   用户的昵称、位置、碳排记录和发布的内容主要存储在浏览器的 **LocalStorage** 中。
*   图片和文本数据会发送至 Google Gemini API 进行处理，但不会被本项目永久存储。
*   社区中的“邻居”数据部分由 AI 生成用于模拟效果。
